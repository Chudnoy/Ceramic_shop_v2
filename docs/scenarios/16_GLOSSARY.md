# 16. Словарь

**Blueprint** — группа связанных Flask-маршрутов.

**Route** — функция обработки HTTP-запроса.

**Service** — законченный пользовательский сценарий и бизнес-правила.

**Database-функция** — низкоуровневый SQL-шаг.

**Транзакция** — группа изменений, фиксируемая `commit()` или отменяемая `rollback()`.

**Атомарность** — «либо всё, либо ничего».

**Компенсационное действие** — ручная отмена изменения вне БД, например удаление файла.

**Инвариант** — правило, которое должно оставаться истинным после операции.

**Ожидаемый статус** — предыдущее состояние в `WHERE status = ?`.

**rowcount** — число реально затронутых строк.

**Исторический снимок** — сохранённые в момент заказа название, цена и количество.

**Many-to-many** — связь многие ко многим через промежуточную таблицу.

**ON DELETE CASCADE** — удаление родителя удаляет зависимые строки.

**ON DELETE SET NULL** — зависимая строка остаётся, внешний ключ становится NULL.

**Session** — данные браузерного сеанса в подписанной cookie.

**CSRF** — атака с нежелательным запросом от имени авторизованного пользователя.

**Fixture** — подготовка окружения pytest.

**monkeypatch** — временная замена функций и зависимостей.

**Интеграционный тест** — проверка взаимодействия нескольких частей.

**Вертикальный сценарий** — путь от HTTP через сервис и базу обратно к ответу.

**Миграция** — версионированное изменение схемы или данных.
