# 1. Контекст и назначение проекта

## Что это за приложение

Ceramic Shop v2 — сайт-портфолио и небольшая коммерческая витрина керамических работ художницы Полины Яланской.

Публичная часть в первую очередь показывает художественную практику: работы, материалы, годы, категории, смысловые теги и авторские описания. Коммерческая функция вторична: посетитель может добавить доступную работу в корзину и отправить заказ, после чего детали покупки согласовываются вручную.

## Почему это не обычный магазин

Для типового товара часто достаточно названия, цены и остатка. Для художественной работы нужны независимые признаки:

```text
опубликована ли работа
предназначена ли для продажи
архивная ли она
доступна, зарезервирована или продана
является ли избранной
к какой категории относится
какие темы с ней связаны
```

Проданная работа может оставаться в публичном портфолио. Выставочная работа может быть видимой, но не продаваться. Архивная работа может быть убрана из основного административного списка, но ещё не удалена физически.

## Пользовательские области

### Публичная часть

- главная страница;
- каталог;
- фильтрация, поиск и сортировка;
- страница отдельной работы;
- категории и смысловые теги;
- отзывы;
- корзина в Flask session;
- оформление заказа;
- страница успешного оформления.

### Административная часть

- аутентификация администратора;
- управление работами;
- быстрое изменение состояния работы;
- категории;
- теги;
- архив;
- управление заказами;
- загрузка изображений;
- статистика.

## Технологии

```text
Python
Flask
SQLite
Jinja2
HTML
CSS
небольшой объём JavaScript
pytest
python-dotenv
Werkzeug
```

Проект сознательно использует ручной SQL без ORM. Это делает связи, транзакции и условные обновления прозрачными.

## Граница текущей версии

Рабочее ядро уже есть, но приложение пока не полностью готово к production. Незавершённые области:

- автоматический CI;
- полноценные миграции;
- фабрика Flask-приложения;
- дополнительная защита страницы успешного заказа;
- окончательная модель количества и складских остатков;
- несколько известных дефектов;
- синхронизация зависимостей и документации.
