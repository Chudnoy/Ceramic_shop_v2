# 10. Административная панель

## Назначение

Админка — рабочий кабинет, а не копия публичного сайта. Она рассчитана на плотные данные, быстрые действия, статусы, фильтры и работу с телефона.

## Структура маршрутов

```text
routes/admin/
├── __init__.py
├── auth.py
├── dashboard.py
├── products.py
├── orders.py
├── categories.py
└── tags.py
```

## Навигация

Базовый шаблон содержит боковую панель, мобильное меню, активный раздел, ссылку на сайт, POST-выход с CSRF, skip-link и `aria-live` для сообщений.

## Работы

Доступны создание, редактирование, быстрое изменение состояния, архивирование, восстановление, окончательное удаление, фильтры, поиск, теги и загрузка изображения.

## Заказы

Интерфейс показывает только допустимые действия:

```text
new: edit, confirm, cancel
confirmed: complete, cancel
completed: read only
canceled: delete
```

Отдельные кнопки лучше общего select, потому что каждое действие имеет свои правила и последствия.

## Дизайн-система

`admin.css` содержит переменные цветов, поверхностей, статусов, радиусов, теней, ширины sidebar и скорости анимации. Это делает интерфейс единым и поддерживаемым.
