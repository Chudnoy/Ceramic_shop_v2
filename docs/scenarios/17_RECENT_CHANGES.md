# 17. Последние крупные изменения

## Новая административная дизайн-система

Админка получила sidebar, мобильную навигацию, активные разделы, единые CSS-переменные, переработанные таблицы и формы и улучшения доступности.

## Защита полной формы работы

Проверка активного заказа перенесена внутрь `update_product_with_tags()`. Запрещённую смену статуса нельзя обойти через полную форму, а проверка выполняется до сохранения изображения.

## Partial checkout

Checkout различает полный, частично недоступный и полностью недоступный состав. Частичный заказ требует явного согласия.

## Точечная очистка корзины

После заказа удаляются только реально оформленные работы. Ошибка не меняет корзину.

## Удалённые ID в session

Корзина замечает ID, которых больше нет в базе, вместо молчаливого исчезновения.

## Route-тесты

Закреплены отказ без подтверждения, успешный частичный заказ, сохранение корзины при ошибке и полный заказ.

## Урок boolean-условий

```python
not value != "1"
```

синтаксически допустимо, но легко инвертирует смысл. Лучше давать промежуточным условиям имена:

```python
confirmation = request.form.get("confirm_partial_order")
confirmation_missing = confirmation != "1"

if has_unavailable_items and confirmation_missing:
    ...
```
