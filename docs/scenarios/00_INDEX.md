## Основная мысль

Ceramic Shop v2 — не просто магазин. Одна запись представляет художественную работу, которая одновременно может быть частью портфолио, объектом каталога и предметом продажи.

Работа может быть опубликована или скрыта, продаваться или быть только выставочной, находиться в архиве, быть доступной, зарезервированной или проданной. Из-за этого приложение выросло из обычного CRUD в небольшую предметную систему с транзакциями и контролируемыми переходами состояний.
