# 7. Оформление заказа

## Зачем повторная проверка

Между открытием корзины и отправкой формы состояние может измениться: работу скрыли, зарезервировали, продали или удалили. Поэтому `POST /checkout` заново вызывает `build_cart_summary()`.

## GET checkout

Маршрут:

1. собирает актуальную сводку;
2. отклоняет пустую корзину;
3. отклоняет корзину без доступных работ;
4. предупреждает о частично недоступном составе;
5. показывает актуальные позиции и сумму;
6. передаёт `has_unavailable_items` в шаблон.

## Частичный заказ

Если часть корзины недоступна, пользователь должен явно подтвердить оформление только доступных позиций.

Правильная серверная проверка:

```python
confirmation = request.form.get("confirm_partial_order")

if cart_summary["has_unavailable_items"] and confirmation != "1":
    ...
```

HTML-проверка не заменяет серверную.

## Позиции заказа

`build_order_item_list()` создаёт исторические данные:

```python
{
    "product_id": product["id"],
    "product_name": product["name"],
    "unit_price": product["price"],
    "quantity": cart[product_id],
}
```

Название и цена берутся из базы, а не из пользовательской формы.

## Создание

В одной транзакции:

1. создаётся `orders`;
2. создаются `order_items`;
3. работы меняются `available → reserved`;
4. выполняется commit только после полного успеха.

Условный UPDATE защищает от гонки:

```sql
UPDATE products
SET status = 'reserved'
WHERE id = ?
  AND status = 'available'
```

## Корзина после результата

```text
полный успех → удалить заказанные позиции
частичный успех → оставить недоступные позиции
ошибка → не менять корзину
```

## Известный дефект текущего commit

В актуальном `routes/main.py` проверка записана с ошибочным двойным отрицанием:

```python
and not request.form.get("confirm_partial_order") != "1"
```

Подробности и исправление: `14_KNOWN_ISSUES.md`.

## Защита страницы успеха

Рекомендуется после создания сохранять:

```python
session["last_created_order_id"] = order_id
```

и разрешать страницу успеха только при совпадении. Сейчас UUID фактически является ссылкой-доступом к контактным данным.
